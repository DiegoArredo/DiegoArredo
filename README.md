# Hola, soy Diego Arredondo 👋

Soy estudiante de **Ingeniería Civil en Computación en la FCFM (U. de Chile)** y **Desarrollador Full-Stack** certificado por Coding Dojo. Me apasiona construir aplicaciones web eficientes, liderar equipos ágiles y resolver problemas que van desde la arquitectura de software hasta el hardware.

### 👨‍💻 Sobre mí
- 💻 **Desarrollador Full-Stack** con experiencia construyendo plataformas web con **React, Django y Node.js**.
- ⚙️ Experiencia en gestión ágil y coordinación de equipos (rol de **Scrum Master** en proyectos universitarios).
- 🔌 Sólido background técnico: diagnostico, mantengo y optimizo hardware a nivel de microelectrónica.
- 🌱 Actualmente profundizando mis conocimientos en **arquitectura de microservicios (Go, RabbitMQ)** y **TypeScript**.
- 🚀 Siempre buscando aprender y construir mejores soluciones, equilibrando la calidad del código con la experiencia del usuario.
